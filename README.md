# 📊 Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer churn using Python to identify patterns and factors associated with customers leaving a telecommunications service.

The analysis focuses on customer demographics, contract types, monthly charges, tenure, and internet service.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## 📂 Dataset

The project uses the Telco Customer Churn dataset containing customer information, services, billing details, and churn status.

## 🔍 Analysis Performed

* Data loading and exploration
* Data type validation
* Missing/invalid value handling
* Churn rate calculation
* Churn analysis by contract type
* Monthly charges vs. churn analysis
* Customer tenure vs. churn analysis
* Churn analysis by internet service

## 📈 Key Metrics

* Total Customers: 7,032
* Churned Customers: 1,869
* Churn Rate: 26.58%

## 📊 Visualizations

The project includes visualizations for:

* Churn Rate by Contract Type
* Monthly Charges vs Churn
* Customer Tenure vs Churn
* Churn Rate by Internet Service

## 💡 Business Insights

The analysis helps identify customer segments with different churn patterns and provides a foundation for developing customer-retention strategies.
